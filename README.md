# 픽업 플래너 - 개인 프로젝트

가챠 게임의 실제 배너와 천장 규칙으로 뽑기를 시뮬레이션하고, 내 재화로 목표 배너에서 원하는 캐릭터를 얻을 확률을 계산해 주는 재화 관리 플래너를 만듭니다.

첫 지원 게임은 명일방주이며, 이후 다른 게임도 데이터만 추가해서 지원할 수 있는 구조를 목표로 합니다.

## 주요 기능

- **가챠 시뮬레이터**: 실제 배너 정보로 1회·10회 뽑기, 천장과 픽업 확률 반영, 배너 종류별 천장 이어짐 반영
  - 시작 상태 직접 설정 (현재 천장 카운트, 픽업 확정 여부)
  - 자유 뽑기(재화 무관) / 내 재화로 뽑기(입력한 재화만큼만, 남은 재화 표시)
- **획득 확률 계산**: 현재 천장 카운트, 뽑기 가능 횟수, 배너 규칙으로 픽업 캐릭터 획득 확률 계산
- **재화 플래너**: 현재 재화와 목표 배너 날짜까지 얻을 수 있는 재화를 합산해 뽑기 횟수로 환산하고 획득 확률까지 계산
  - 한국 서버 기준이며, 중국 서버가 약 6개월 먼저 운영되므로 중국 서버의 가챠 일정·이벤트·판매 예정 패키지를 한국 서버 일정으로 반영해 미래 배너까지 계산
  - 합산 항목을 사용자가 선택: 정기 수입(일일 퀘스트·로그인 등), 이벤트 보상, 패키지
  - 패키지는 기간 한정 패키지와 상시 판매 패키지를 구분하고, 오리지늄은 금액 구간별 상시 판매로 취급하며, 종류와 개수를 사용자가 직접 선택
  - 이벤트별 판매 패키지와 오리지늄 구매 횟수를 선택하고, 금액 구간별 초회 구매 보너스도 계산에 반영
  - 무과금 기준이 기본이고, 패키지·오리지늄을 포함하면 늘어나는 뽑기 횟수를 비교로 표시
- **기록과 통계 (회원)**: 시뮬레이션 기록, 최고 등급이 나오기까지 평균 횟수, 설정 확률과 실제 결과 비교
- **관리자**: 게임, 배너·픽업, 확률 규칙, 정기 수입, 이벤트 보상, 패키지 관리와 게임 데이터(JSON) 가져오기
- **여러 게임 지원 구조**: 재화 종류, 환산 비율, 등급, 천장 규칙, 정기 수입을 테이블로 분리해 게임별 코드 분기 없이 확장
- **계정 연동**: 게임 계정의 재화를 자동으로 가져오는 선택 기능이며(회원 전용), 비공식 방식이라 "실험적 기능"으로 경고와 함께 제공
- **회원과 비회원**: 시뮬레이터는 비회원도 사용할 수 있고, 기록·통계·재화 플래너 저장·계정 연동은 회원 전용

## 프로젝트 구조

> 구현을 시작하기 전의 예정 구조입니다. 코드가 확정되면 실제 구조에 맞게 수정합니다.

```text
.
├── docs/                      # 프로젝트 산출물 문서
├── guides/                    # 커밋 정책, 고객 요청사항
├── src/main/java/
│   ├── controller/            # Servlet: 시뮬레이터, 확률 계산, 플래너, 관리자
│   ├── service/               # 시뮬레이터, 확률 계산, 수입 예측, 재화 가져오기(어댑터)
│   ├── dao/                   # Oracle DB 접근
│   ├── model/                 # 게임, 배너, 규칙, 회원 등 데이터 객체
│   └── util/                  # 공통 유틸
├── src/main/webapp/
│   ├── WEB-INF/
│   ├── css/
│   ├── js/                    # Chart.js를 사용한 확률 그래프
│   └── *.jsp                  # 화면 (View)
└── README.md
```
