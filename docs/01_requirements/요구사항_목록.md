## 2. 비기능 요구사항

### 2-1. 데이터
|ID|요구사항명|근거|
|--|--|--|
|Data-001|재화 종류, 환산 비율, 등급, 천장 규칙, 정기 수입은 게임과 연결하여 게임별 데이터로 저장한다.|NEEDS_02, C4|
|Data-002|배너, 캐릭터, 이벤트, 패키지 정보는 서버(한국, 중국)와 일정의 확정·예상 여부를 구분하여 저장한다.|NEEDS_07, NEEDS_19|
|Data-003|회원의 천장 상태(게임별, 배너 종류별), 재화 계획, 시뮬레이션 기록은 회원별로 연결하여 저장한다.|NEEDS_11, NEEDS_12, NEEDS_13|
|Data-004|회원이 탈퇴하면 해당 회원의 정보와 관련 데이터도 함께 처리한다.|NEEDS_15|
|Data-005|캐릭터, 배너, 재화의 이미지는 위치 정보를 게임 데이터와 연결하여 저장한다.|NEEDS_20, C7|

### 2-2. 보안
|ID|요구사항명|근거|
|--|--|--|
|Sec-001|회원은 자신의 천장 상태, 재화 계획, 시뮬레이션 기록만 조회, 수정, 삭제할 수 있다.|NEEDS_11, NEEDS_12, NEEDS_13|
|Sec-002|로그인하지 않은 사용자는 기록·통계, 재화 계획 저장, 계정 연동, 내 정보 화면에 접근할 수 없다.|NEEDS_12, NEEDS_13, NEEDS_14, NEEDS_15|
|Sec-003|게임 데이터 관리와 가져오기 기능은 관리자만 사용할 수 있다.|NEEDS_16, NEEDS_17, NEEDS_18, NEEDS_19|
|Sec-004|비밀번호는 해시하여 저장한다.|NEEDS_15|
|Sec-005|재화 수량, 뽑기 횟수, 날짜, 확률 등 입력값은 올바른 형식인지 검증한다.|NEEDS_03, NEEDS_06|
|Sec-006|계정 연동에 사용한 게임 계정의 인증 정보는 저장하지 않는다.|NEEDS_14|

### 2-3. 사용성
|ID|요구사항명|근거|
|--|--|--|
|UI-001|시뮬레이터는 로그인하지 않아도 바로 사용할 수 있다.|NEEDS_11, C2|
|UI-002|처리 결과와 입력 오류는 사용자가 알 수 있도록 안내한다.|NEEDS_03, NEEDS_06|
|UI-003|회원 탈퇴, 데이터 삭제처럼 되돌릴 수 없는 작업은 실행하기 전에 한 번 더 확인을 받는다.|NEEDS_15, NEEDS_16|
|UI-004|조회 결과가 없으면 없다는 안내를 보여 준다.|NEEDS_12, NEEDS_13|
|UI-005|재화 플래너는 무과금 기준을 기본 화면으로 보여 준다.|NEEDS_10|
|UI-006|이미지가 없거나 불러오지 못하면 글자로 내용을 보여 주고 기본 이미지를 보여 준다.|NEEDS_20|
|UI-007|게임 이미지의 저작권이 게임 회사에 있고 비공식 팬 프로젝트임을 화면에 안내한다.|C7|
